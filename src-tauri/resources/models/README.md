# Bundled TrustMark Models

This directory contains the official Adobe TrustMark Q ONNX encoder and decoder used by the Rust `trustmark` crate. Tauri includes both files as offline bundle resources; the application does not download models at runtime.

See `../../../THIRD_PARTY_NOTICES.md` and `../../../docs/build-and-release.md` for source, size, hashes, and redistribution notes.
