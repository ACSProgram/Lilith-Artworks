## UX-09 当前状态

已实现：

- 同参数无签名 JPEG 会话缓存，以及源摘要、参数、TrustMark ID、缓存摘要和尺寸重校验；失效缓存删除后重算。
- 前端显示渲染、JPEG 编码和 C2PA/时间戳耗时。
- 质量预览与签名发布注册为单一活动认证任务；按钮可请求取消，切换分支或离开页面也会取消旧任务。
- 图像、缓存、TrustMark、JPEG、C2PA、回读和摘要阶段之间检查取消；取消发生在发布前时由临时文件 RAII 清理。
- 时间戳请求禁止重定向，30 秒硬超时，等待时每 100 ms 检查取消。
- 外部输出开始原子发布后不再中断，必须完成记录提交或既有失败恢复，避免向前端返回虚假的“已取消”。

实现限制：TrustMark 推理、单次图片编解码和 C2PA SDK 本地调用不能在函数内部强制终止，取消会在下一阶段边界生效。时间戳等待可快速取消，但其不持有私钥的网络线程最多继续到 30 秒自身超时，且不能发布文件或写入记录。

## 放行顺序

1. 维护者在干净范围执行 `npm ci`、release metadata/legal、前端 build/test、Rust fmt 与完整库测试，并构建本地 NSIS。
2. 完成本页极端人工验收；失败项修复后递增候选版本，不复用已推送标签。
3. 人工提交并推送，等待 Windows CI；需要签名时先配置证书、密码和时间戳 secrets。
4. 从同一已验收提交创建一次 `v0.1.0-rc.2` 标签，由 workflow 生成 draft prerelease。
5. 下载 CI 产物复验安装、启动、仓库创建、托盘/退出、一次提交/恢复、一次发布/识别/取消和卸载保留；核对全部资产摘要、SBOM、provenance 和签名状态。
6. 将本轮人工证据写入 `docs/planning/archive/`，把 `rc.1` 标为已被替代但不删除标签或资产，再公开 draft。
