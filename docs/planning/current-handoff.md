# 当前任务交接

更新时间：2026-08-16

## 当前发布基线

`v0.1.0-rc.2` 已发布。它是供评估和内部测试使用的预览版，不是正式版，也不应承载唯一副本、不可替代作品或生产数据。`rc.1` 与 `rc.2` 的标签和发布资产均不可移动、覆盖或复用；任何发布后的代码、schema、应用标识或签名声明变化都必须使用新的版本和标签。

RC2 使用 repository schema v9 和应用标识 `com.lilith.artworks`。RC1 及更早候选版的作品仓库、设置和应用数据与 RC2 不兼容，项目不提供迁移支持。RC2 只能使用新建仓库；保留旧数据时必须继续使用创建它的原版本并维护独立备份。

RC2 已完成内容、验证结果和维护者人工验收已归档到 `docs/planning/archive/rc2-release-2026-08-16.md`。更早的发布前审查和延后质量清单见 `docs/planning/archive/rc2-pre-release-audit-2026-08-16.md`。

## 下一阶段入口

- 继续发布候选版时先把全部版本元数据提升到 `0.1.0-rc.3` 或更高版本；不得从 RC2 标签重新生成不同资产。
- RC2 发布后已把失效的 `actions-rust-lang/audit@v1` 替换为 `rustsec/audit-check@v2.0.0`；该修复属于 `Unreleased`，必须随下一版本发布，不能回写 RC2 标签或资产。
- 开始 `0.1.0` 正式版工作时，重新激活发布前审查归档中的崩溃一致性、授权与退出、稳定读取、规模、前端恢复、可访问性和最终用户文档清单。
- 正式版前补齐极端大文件与高像素压力、各处理阶段取消、异常 RFC 3161 服务、损坏文件恢复、普通用户安装和 Authenticode 签名验收，并记录可复查证据。
- 项目规则继续禁止代理执行 GUI 自动化；桌面交互、真实模型、第三方 C2PA 回读和安装包验收由维护者手工执行。
