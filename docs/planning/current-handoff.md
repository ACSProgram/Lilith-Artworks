其余工具直接进入绘制，没有额外的模式开关。选中绘制工具后按下指针即开始画，不再触发选中与框选；切工具
会清掉选中、拖拽快照与框选基底，锁定后工具禁用并退回选择。绘制中的笔迹画在 DOM 2D 叠加层上（世界坐标
直接映射到设备像素，线宽与落库结果天然一致），GPU 缓冲只在落库后重建一次，不在每次 `pointermove` 重建。
Shift 把自由笔约束成直线、矩形约束成正方形、椭圆约束成圆，直线与箭头吸附 45°。松手才编码包围盒与
几何 BLOB，交给控制器**串行**落库：先保存未落库的变换，再创建条目并重读几何；预览留到新笔迹进缓冲
才撤，提交失败或切画板时也撤，中途不闪空白。拖拽不足 3 个 CSS 像素按误点处理，`pointercancel` 按取消
而非落库。行为变化见 `CHANGELOG.md` 的 `## Unreleased`，模块口径见
`docs/modules/pin-board.md` 的「绘制」，落地结论见 `docs/planning/pin-board-strokes-plan-2026-10-20.md`

- 当前功能契约以 `docs/architecture/`、`docs/modules/` 与 `docs/guides/` 为准。

  段落与本文件中删除，不在表层留下“已通过”的痕迹。

  `docs/guides/release-policy.md`。
