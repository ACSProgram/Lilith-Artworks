# RC2 发布与验收归档

归档日期：2026-08-16

## 发布结论

- 维护者确认 `v0.1.0-rc.2` 已发布；该标签与发布资产保持不可变。
- RC2 定位为供评估和内部测试使用的预览版，不是正式版，不应承载唯一副本、不可替代作品或生产数据。
- RC2 使用 repository schema v9 和应用标识 `com.lilith.artworks`。RC1 及更早候选版的作品仓库、设置和应用数据不受支持且视为不兼容；RC2 不提供迁移路径，只支持新建仓库。
- 本归档不推断安装包的 Authenticode 状态；签名、校验和、SBOM 和 provenance 以对应 GitHub Release 资产及工作流证据为准。

## 已完成范围

- 完成整仓灾备、自动备份失败退避与通知、恢复清理队列、仓库完整性检查和跨模块共享运行锁。
- 完成分支历史、fork、恢复、精简、检查点、发布锁定和紧凑历史工作区；总览可直接精简所选分支，唯一归属节点可在不离开总览时选择分支。
- 完成 C2PA 强制签名、可选区域 TrustMark、质量预览缓存、认证记录仓库副本、再次导出、识别和跨 Artwork 溯源。
- 质量预览与签名具备合作式取消；RFC 3161 请求采用无重定向客户端和 30 秒硬超时。界面显示生成状态，并只在任务确认取消后报告取消完成。
- 设置弹窗、分支信息带、时间轴占高和质量预览交互完成最终 UI 整理，维护者已在真实窗口中人工验收并确认无问题。
- 完成 Windows CI、版本和 schema 元数据校验、依赖审计、第三方许可闭包、CycloneDX SBOM、SHA-256、构建来源证明和标签发布工作流。

## 验证与验收记录

- `npm test`：12 个测试文件、40 个用例通过；认证大小估算的延迟请求已有无效适配器返回值回归覆盖，未再出现 Vitest 未处理异常。
- `npm run build`：通过。
- `cargo test --manifest-path src-tauri/Cargo.toml --lib authenticity::`：21 个通过，1 个 fixture 重生成入口按设计忽略。
- `cargo fmt --check --manifest-path src-tauri/Cargo.toml`：通过。
- 维护者确认常规桌面流程和最后一轮历史、设置、预览 UI 已人工验收；TrustMark/C2PA 发布、导出和识别已实际使用并正常。
- GitHub 发布事实由维护者确认；未在本地重复下载或检查已发布资产，因此不在此虚构安装包签名或逐资产复验结论。

## 发布时保留的限制

- TrustMark 推理、单次图片编解码和 C2PA SDK 本地调用不能在函数内部强制中断，取消会在下一阶段边界生效。
- 极端大文件、高像素、各阶段取消延迟、异常时间戳服务、普通用户安装和 Authenticode 仍属于正式版前需留存证据的质量工作。
- 延后到 `0.1.0` 的完整工程质量清单见 `rc2-pre-release-audit-2026-08-16.md`。
