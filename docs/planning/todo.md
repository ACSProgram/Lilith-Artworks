## 二、待验证 / 待人工验收

按 `docs/guides/release-policy.md` 的「人工门槛」，以下项目对 `0.2.x` 仍未执行。可程序判定的
部分已由发布前的自动化压力测试接管（`src-tauri/tests/`，见 `docs/guides/validation.md` 与
`docs/user/stress-test-report.md`），保留人工复核手感；界面视觉、交互手感与桌面集成仍由维护者
手工验收。

已自动化覆盖、保留人工复核手感：

- 各处理阶段的取消边界（提交、恢复、精简、检查点、整仓灾备、认证签名）；
- 损坏文件的恢复路径（snapshot/delta 缺失或摘要不匹配）；
- 画板 DDS 损坏、缺失、孤儿文件；
- 极端大文件与高像素压力的错误恢复。

仍需人工：

- 异常 RFC 3161 时间戳服务的失败与超时行为；
- 画板在结算/仓库切换期间的保存失败恢复，含本轮新增的「结算失败时中止切换并提示」行为；
- 任务调度总控与空闲链路校验批次的界面项：空闲校验进行中触发取消、校验失败警告的展示与
  「重新校验此分支」清除路径、快速检查与空闲校验的组合、大链校验期间前台操作的响应性、
  校验失败后继续手动提交是否正常；
- 统一清理体系批次 A–F 的界面项：清理失败只体现在日志与队列时命令的成功/失败文案与改动前
  一致、设置页「文件清理」区的队列列表与重试/扫描/确认清理交互、完整性检查发现画板 DDS
  问题时的警告文案、创建备份回收残留暂存目录时的附加说明。

不做自动化：

- 断电持久性——`Child::kill()` 不触及操作系统与磁盘缓存、也不保证目录项落盘，该保证由操作
  系统、磁盘与 SQLite `synchronous = FULL` 声明承担。
