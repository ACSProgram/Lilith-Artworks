# 待办清单

本文件是本项目**唯一**的未完成事项清单：尚未实现、尚未验证或需要维护者决策的内容都记在这里。
已完成的批次写归档（`archive/README.md`），当前批次的执行状态写 `current-handoff.md`。

更新时间：2026-09-18（对应版本 `0.2.0-alpha.2`）

## 一、待实现 / 待补强

| 事项 | 现状 | 影响 |
| --- | --- | --- |
| 仓库完整性扫描覆盖画板 DDS 文件 | 设置页"仓库完整性"目前只扫描历史链（snapshot/delta）与认证受控文件（最终成品、认证副本）。整仓灾备的清单会对 `boards/**/*.dds` 记录 SHA-256，但普通扫描不校验其内容语义 | 画板纹理损坏只能在恢复或实际读取时暴露 |
| 分支工作文件路径的清空约束 | 新增：允许清空工作文件路径，但同一 Artwork 只能有一个分支留空（`source_path_key` 非空且唯一） | 第二个分支清空会被拒绝并提示；需要人工确认提示文案是否符合预期 |
| 长任务与灾备调度并行的降级策略 | 纹理读取持共享读租约；灾备/扫描持仓库操作锁期间画板浏览可继续但画板写入会等待 | 实测卡顿不可接受时再评估（如缩略图兜底提示） |
| 超期临时目录清理 | `repository/temp` 中会遗留认证预览会话目录（观察值约 40 MB） | 长期使用会累积占用；可考虑打开仓库时清理超期临时目录 |

## 二、待验证 / 待人工验收

按 `docs/guides/release-policy.md` 的"人工门槛"，以下项目对 `0.2.x` 仍未执行：

- 极端大文件与高像素压力的内存、取消、退出与错误恢复（使用正式支持上限附近的图片与工作文件）；
- 各处理阶段的取消边界（提交、恢复、精简、检查点、整仓灾备、认证签名）；
- 异常 RFC 3161 时间戳服务的失败与超时行为；
- 损坏文件的恢复路径（snapshot/delta 缺失或摘要不匹配）；
- 普通用户账户安装、Authenticode 签名与时间戳验证；
- 第三方工具回读 C2PA，并用随包模型验证 TrustMark 实图；
- 从上一公开候选版执行安装升级与卸载。
